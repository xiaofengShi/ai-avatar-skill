01 / 能做什么

围绕用途设计，而不是套滤镜。

多数头像工具问“要什么风格”；Editorial Avatar 先问“这张肖像用在哪里”——大会主页、深色团队页和开发者社区，各自对应不同的设计。

按用途设计

提供照片与使用场景；用途不明确时先澄清，再设计构图、造型、光线与配色。

风格与局部修改

默认半写实手绘，可指定其他画风、保留眼镜或调整表情，并在认可版本上继续修改。

真实尺寸裁切检查

以 40、64、128、256 px 圆形裁切和深浅两种背景检查头像——按人们真正看到的尺寸验收。

两种使用入口

Codex skill 连续完成澄清、设计、生成与预览；ChatGPT 两阶段 prompt 把方案与生成分开，避免跳过用途澄清。

02 / 工作方式

从照片到肖像，四步完成。

  1. 附上照片和用途

    一张照片加上使用场景即可开始，例如“用于 GitHub 和 Hugging Face，保留眼镜”。

  2. 取得设计简报

    用途不明时助手先提问；明确后针对场景设计构图、服装、光线与配色。

  3. 生成肖像

    由你的 Codex 或 ChatGPT 环境中的图像能力出图。本项目提供工作流，不提供模型或额度。

  4. 预览并迭代

    检查真实尺寸的圆形裁切，在认可的版本上继续修改：去眼镜、调整微笑、适配新场景。
