# Editorial Avatar

先阅读并执行 [共同设计流程](references/workflow.md)。它是中文 ChatGPT prompt 的维护源；[英文译本](references/workflow.en.md)用于生成英文 ChatGPT prompt。

## Codex 执行入口

- 查看用户照片；默认半写实手绘方向可使用 [风格参考](references/style-anchor.png)。这是一张 AI 生成的虚构人物图，只用于绘画语言。用户明确指定其他风格时按其要求。
- 调用实际可用的 `image_gen`。使用本地输入时先查看图片，再将风格图、人物图及必要的编辑基底分别传入并标明作用。双图通常为图 1 风格、图 2 人物。没有图像工具时说明缺失，提供可转交的简报；不自行安装依赖、切换付费 API 或声称已生成。
- 编写简报时先表达用途和完整画面，再加入身份保留项与本次编辑要求。不要把流程全文当成生成 prompt，不给用户列摄影参数问卷。
- 保存项目使用的成片及实际发送给工具的简报。保存记录应使用可移植路径；不额外复制无关个人资料。

## 头像预览

当用途是头像，保存图像后运行随 skill 提供的脚本（路径相对本 skill）：

```bash
python3 scripts/preview_avatar.py /path/to/avatar.png --output /path/to/preview.html
```

脚本仅使用 Python 标准库，生成含图片的离线 HTML，不上传、不修改原图。打开并实际查看 40、64、128、256 CSS 像素的圆形裁切及浅深底色；浏览器应使用 100% 缩放。默认居中裁切，不能代表平台所有裁切算法。只有实际看过才能说检查完成。

支持 PNG、JPEG、WebP、GIF 的文件签名识别；解码仍由浏览器完成。输入不是可显示图像时应报错或说明缺陷，不将签名检测等同于完整图片验证。输出已存在时默认拒绝覆盖；确认可替换后使用 `--force`。

需要与原图一起存入仓库时，可用 `--linked` 生成相对引用版，避免重复嵌入图片；分享时必须同时保留图片文件。
